# 梯度下降算法

* 是什么：目标是最小化损失函数的值，通过沿着梯度负方向更新参数。

* 公式是什么：参数更新公式

* 批量梯度下降算法是什么，具体是怎么计算的？ 随机梯度下降算法、小批量梯度下降算法。

  * 批量梯度下降算法的话，损失函数是有一个求和的，比如均方误差，损失函数对参数求导之后，还是有求和的，这样就能把每个样本值参与到梯度值中。

* 实战：你在训练一个图像分类模型，损失曲线如下：

  前10轮损失下降很快，但之后震荡剧烈，验证精度不再提升。
  你会尝试调整哪几个超参数？为什么？

* 梯度下降的局限性：保证收敛到梯度为0，不保证全局最优；对超参数敏感；只有凸函数才能保证收敛到全局最优。

* 学习率大的话，会怎样，小了呢？ 大的话，每次参数更新变化比较大，可能不容易收敛；小的话，更新极其缓慢，容易卡在局部最优；

* 鞍点：多变量微分可能出现的问题。不是局部最大也不是局部最小，是梯度为0；梯度消失：梯度反向传播时，梯度越来越小，参数更新依赖梯度，梯度接近于零参数就不更新了；梯度爆炸，梯度指数级别增长，每更新一次参数，损失函数的值变得巨大。

* 对数据归一化能加速梯度收敛。 等高线是损失函数的值相等的点连成的曲线。在每一圈等高线，每次都沿着等高线垂直的方向更新，能最快指向最小值。 不归一化的话，等高曲线是椭圆，每次更新箭头左拐右拐，效率低。

# 反向传播算法

* loss.backward(); 干嘛的？在多层神经网络中，计算每个参数的梯度，给梯度下降算法用。Pytorch中，计算出的梯度会存储在每个张量的 `.grad` 属性中（需要该张量设置 `requires_grad=True`）。

* 知道他的背后：前向传播时会构建计算图，反向传播时遍历这个计算图。

* 前向传播：是指把输入数据送入神经网络，逐层计算，得到预测值的过程。前向传播得到预测值。 

* 参数更新是优化器(SGD, Adam)根据计算得到的梯度执行的：op timizer.step()

* 这样配合的

  ```python
  
  pred = model(x); 前向传播
  loss = criterion(pred, y);  	计算损失
  
  optimizer.zero_grad();
  loss.backward();
  optimizer.step();
  # 梯度会累加，如果调用十次反向传播，再调用一次优化器，那么这次更新会基于梯度的累加一次性更新；
  ```

* 整体流程：前向传播（得到预测值）——计算损失——反向传播（计算梯度）——优化器更新参数

# 卷积

## 卷积是什么？为啥transformer不用卷积用点积？

* Transformer的点积能一次性计算出输入序列任意位置之间的相似度，但是卷积每一次只能看到卷积核大小的信息。如果想要看到距离较远的词的信息，必须要堆叠很多层，**这样的话参数和时间复杂度都会变很高**。 （卷积建模距离d的依赖，时间复杂度为O（d）;

卷积适用于处理计算机视觉的任务。Transformer为自然语言处理设计，需要捕捉序列中任意两个位置之间的长距离依赖。 **而卷积因为输出特征图上的每个点只依赖于输入的局部窗口。** 需要很多层才能扩大视野。

## 卷积的计算公式？ 

* **卷积核在输入矩阵上移动，输入矩阵和卷积核上对应位置的元素相乘，然后所有元素再相加，得到这个位置的输出。** 没有说清图片有多通道，卷积核的输出也是多通道吗； **输出通道数等于卷积核的个数，是一个超参数，由设计者指定。** 卷积核的深度必须等于输入特征图的通道数。

  自然语言描述：对于 RGB 图片，每一个卷积核都有 3 通道。一个卷积核在图片上移动，是这样产生输出的：对于 R 通道，卷积核在输入矩阵上移动，输入矩阵和卷积核上对应位置的**元素相乘**，然后所有元素**再相加**；因为有三个通道，所以将这三个通道的**输出值相加**；再**加一个偏置**，得到输出特征图的一个数字； 一个卷积核作用在图像上，最终输出位置上的每一个值都是这么来的。 如果有多个卷积核，每个卷积核的输出叠起来，就是多通道；

* **一个卷积核负责检测一种特征**，比如边缘、纹理、颜色组合；一个卷积核扫完整张图片得到一张特征图；64个卷积核得到64张特征图，因此输出通道数是64。**还需要多个卷积层，用来提取深层次的特征**

## 卷积的时间复杂度：

假如正方形核，边长K，输入图尺寸：H1 W1 C1(高、宽、输入通道数)，输出特征图的尺寸：H2 W2 C2， 卷积层时间复杂度：K^2 x C1 x H2 x W2 x C2;

* 一个卷积例子：输入224 224 3 输出 224 224 64 卷积核3 3 3；

* 输出长宽公式：
  $$
  \text{Output} = \frac{N + 2P - K}{S} + 1
  $$
  输出的长、宽由公式计算得到。 输入长度加上2倍填充P 减去 核的边长，除以 stride步长（卷积核一次移动几个像素），下取整，再加一。

  卷积核的深度必须等于输入特征图的通道数C1，所以每个卷积核是一个3 3 3的张量；

## 卷积核的参数：

* 卷积核大小是设计者自己设置的； **卷积核的元素值不是人为指定的**，是反向传播和梯度下降学习得到的；

* ```python
  import torch.nn as nn
  conv = nn.Conv2d(
      in_channels=3, # 要处理图片的通道数量
      out_channels=128, # 卷积核的个数=输出通道数
      kernel_size=3, # 卷积核大小，3x3 的省略样式，可以显式指定长宽
      stride=1,# 步长
      padding=1, # 填充，影响输出的长宽
  )
  ```

# Transformer 前景知识点

## 点积相似度

​	点积相似度的计算公式。两个向量点积的结果越大，说明夹角越小，两个向量的相似度越高。

* **为啥点积的结果能衡量相似度**？ 点积的几何意义是两个向量的模长乘以夹角的余弦值，点积结果越到说明他们的模长和夹角越接近。  嵌入向量Embedding负责把离散的符号（词、物品等）映射到连续向量空间中的点，这个空间被设计成，现实中语义相近的实体，嵌入向量在空间中也接近。
* 还有余弦相似度。点积的结果处理两个向量的模长。

## 嵌入层

 本质是一个矩阵，大小是 词汇量总数X嵌入向量的维度。矩阵每一行对应一个词向量，行号就是这个词在词汇表的编号。

深度学习模型中，词向量一般不用外部预训练好的，而是让模型自己学习。

工作原理：输入一个词的索引，例如5，嵌入层取出矩阵地5行的向量作为输出，在训练过程中，这些**向量会通过反向传播更新**；

## 层归一化Layer Norm

* 什么作用：深度学习模型Transformer和RNN常用，稳定训练加速收敛。

* 公式：计算这个向量所有维度的均值和方差，然后每个维度归一化（分母是根号下方差加上一个微小的整数），再进行缩放和平移。 **同一样本**的**不同特征维度**计算均值和方差。(归一化的均值和方差都来自自己) ；Batch Norm是同一批次的**不同样本**的**同一纬度**，计算均值和方差。

* 为什么不用batch Norm？ （CNN常用 group norm），1Batch Norm在处理变长序列时，填充的Token会污染真实值。2从BN的计算公式看，batch的size大，归一化才更有效；而深度学习语言模型在训练推理时，一个batch是比较小的，甚至是1。

  * 每一个batch里面的序列长度不一样。 一个batch有三个句子，但是三个句子的长度不一样，

  * （填充的一个padding是一个零向量，不是向量的某个位置）；具体计算是：不同句子的同一个索引位置的向量，做一个归一化。

    那么对同一纬度的所有位置，有的地方2个值，有的地方只有3个值，把真实Token 和 padding Token混在一起。 （NLP任务会填充padding。）

* 层归一化的两个可学习参数作用？有能力恢复恒等映射。设置两个值，让归一化操作之后的值恢复到归一化之前。

* `nn.LayerNorm(512)` 在哪个维度归一化？输入 `(batch, seq_len, 512)` 输出形状？
  * 一般来说会对输入张量的**最后一个维度**进行归一化。这里的512指明了需要归一化的特征维度的大小。 Batch 是句子的个数，seq_len是句子长度（长度为3，有三个词向量，512是Token的维度） 想象一下这个张量什么样？**batch个二维数组。**

* 问题8：在 Transformer 中，层归一化通常放在哪里？是“Post-LN”还是“Pre-LN”？二者有何区别？

  * 原论文中，先做注意力层/FFN ，然后残差，最后归一化；这是Post-LN; Pre-LN是先做层归一化，再进入注意力层/FFN，最后残差。 有什么区别？
  * 关键区别：梯度流动分析（数学原理未分析）。Post-LN 的梯度早期会消失/爆炸，需要学习率预热。Pre-LN梯度可以从深层无损传到浅层。更稳。

## Transformer的位置编码

​	position是指这个向量在句子中的位置；维度1、维度2等等是指向量的第2个位置、第三个位置；

* 为什么正余弦编码要这么设计？从一个合格的位置编码的角度考虑。两个位置之间的向量距离能反应原始序列中的距离。 
  * 关键1:**相对位置可以线性表示。** 模型就能够利用线性变换学习相对位置的关系。 具体：任意一个position加k的位置编码都可以通过position的位置编码 进行一个**固定**的线性变换得到。 
  * 可以表示多尺度的位置信息。对于一个向量，根据公式可以看出，它的低维度，频率高，变化大，能区分精细位置；高纬度部分，频率低，周期大，用来衡量全局位置。
* 为什么位置编码直接相加就有效果了？
* 正弦余弦位置编码的公式
* **可学习位置编码**
  * 计算方法：预设一个句子最大长度Lmax,  可学习位置编码实际就是一个矩阵，大小为Lmax X dmodel （L max是句子的最大长度）。 一个句子实际就是一个二维矩阵，使用的时候，每一个句子都直接逐元素相加这个位置编码矩阵。
  * 特点：这个矩阵会在训练过程中反向传播更新。
  * 区别：**不能外推**。测试时如果遇到长度大于Lmax的句子，无法处理。 但是固定位置编码，可以外推到任意长度。
  * BERT GPT 通常使用可学习位置编码。
  * 相对位置编码。
* 为什么正余弦位置编码选择与原始嵌入向量相加，而不是维度拼接？
  * 拼接的坏处：输入向量维度翻倍，后续权重矩阵全部翻倍，计算量和内存都爆炸增加；
  * 相加的话，本质上可以写成线性变化，而注意力机制的核心就是线性变换和点击，相加后的向量，每一个位置融合了语义信息和位置信息，模型是可以学到如何利用这种混合表示。简单来说就是相加的效果足够使用，而且简单。

## QKV矩阵

​	**为什么点积之后要除以根号下向量的维度**，而不是直接除以向量的维度。 为了让点积的方差为1，不让过大的值进入sofa Max。如果不缩放，点积的数值大小会随着d_k的增大而增大。 可以从数学角度证明，点积之后的方差是向量的维度，所以除以标准差，让方差等于1。

* 过大的值进入soft Max 会导致梯度很小。

* 为什么要除以根号下向量的维度？能不能带不带根号？

* 为什么 σ₀ 要对 z₀ 求导 ：在实际反向传播中，我们需要知道**每一个输出 σ_i 对每一个输入 z_k 的偏导**，形成一个雅可比矩阵。

* 思考：权重矩阵是整个模型共享的。每一个句子，都用这个。但是因为输入X不同，产生的QKV也不同。 比如模型有8个头，每个头有自己的一组权重矩阵。 

  * 关于注意力矩阵：一个句子（二维矩阵，每一行是一个词向量）X；X乘以权重矩阵，得到Q，Q的尺寸是多少？（seq_len, d_model/num_heads)。 Q点积K得到的注意力矩阵： 第一行第一个元素，代表第一个词向量的Q和第一个词向量的K做点积得到的注意力分数，整个第一行是第一个词向量对这个句子所有的词向量的注意力得分。所以计算SoftMax时候，是**对注意力矩阵的每一行**进行的。

* 权重矩阵W_Q, W_K, W_V参数的更新方式？是否一致？

  更新方式完全一样，都是反向传播计算梯度，然后梯度下降算法更新参数。但是因为他们在损失函数的位置不同，所以每一次的梯度也不同，学习到的内容都不同。

## 前馈神经网络FFN

* 为什么需要？ 自注意力的点积、加权求和，都是线性变换。**前馈层为了给模型增加更强的拟合能力**。引入非线性变换。

* 组成：两层全连接层，中间有一个ReLU激活函数。 非线性是ReLU激活函数提供的，两个全连接层主要提供了很多可学习的参数，增加模型拟合能力。

* 具体操作：对每个Token单独计算，先把向量维度扩大4倍，经过激活函数，再缩小到4倍。 为什么中间维度要放大到4倍？ 4倍是经过证明最好的选择。在1到4倍之间，性能显著上升；大于4倍之后，比如8倍，16倍，性能提升不高，参数量显著增加，计算量显著增长。

* **Transformer 的 FFN 中对每个位置的变换是独立的，那不同位置之间会共享参数吗？** 会共享参数。 参数会不断更新吗？既然不断更新，怎么还能共享呢？是每次作用一个token，就计算梯度，然后更新参数，再用更新的参数继续下一个token计算吗？

  * 共享参数的时机和参数更新的时机。 共享参数是指，在同一次前向传播，对于序列中的不同token，用的是同一组权重矩阵。而，参数更新是整个batch的前向+反向完成之后，根据所有位置、所有样本的梯度总和，进行一次更新。

* 前馈神经网络的层数有要求吗？放大向量的维度有要求吗？

  一般是2层。2层是性能和效率的平衡。通用前馈神经网络是层数是任务具体决定的。

  放大的维度是4倍。如果低于4倍，模型可能欠拟合，如果高于4倍，参数量会巨大，但是模型提升的性能很少甚至过拟合。

## 残差

* 解决的问题：残差能让模型层数和参数大幅增大。
* 如何理解：反向传播时，经过每一层，**梯度都要乘以**这一层权重矩阵的参数，如果所有权重矩阵的参数都小于1，梯度会减小的非常快；导致浅层参数直接不更新；（这句话的理解，用一个例子手算感受一下，链式法则的时候怎么会乘以权重矩阵的参数，直接用标量）
  * 梯度消失/爆炸； 什么是梯度消失/爆炸？
  * 网络退化； 增加网络层数导致训练误差上升。 （多重非线性复合之后，恒等映射难以学出来。） 让网络的一部分层去学习残差F(X) = H(X) - X ,H(X) 是目标函数。
* 为什么直接相加就可以？网络如果相差很多层，还能直接相加吗？
  * 维度匹配：向量经过自注意力计算再输出，维度不变；学习残差比学习原始映射更容易；
  * 残差网络的输出是 x + F(X), F(X)是当前模块学习到的残差函数。反向传播时，求导之后有个常数项1，能保证有一部分梯度可以被利用。

## MoE

一句话说明MoE是干嘛的？以transformer为例，token 都走一个 FFN； MoE有许多FFN，不同的token走不同的FFN；

计算量可控，巨大模型参数着增加模型表达能力。

整体流程：MoE 中，**路由器**根据输入为每个 token 选择最合适的 **Top-K 专家**，只让这些专家计算，然后**加权聚合**输出；增加了模型容量（很多专家），又控制了每次计算量（只激活少数专家）。

每个token向量独立选择专家。 在视觉MoE中，整张图片的patch token 走同一个专家组合。

* 核心组件：
  * 专家：每一个专家是一个前馈神经网络Feed-Forward Network，通常两个线性层+一个激活层，有自己的参数；
  * 路由器：一个线性层，输出每个专家的得分；矩阵大小 [向量维度，专家数]。这是一个可学习的矩阵。
  * 根据分数选择top-K专家；
  * 聚合：将**选中的**专家的输出按照分数加权求和。
  * 输出：聚合后的向量，作为MoE层的输出；

劣势：专家路由、存储巨大参数、负载均衡、多卡通信；

举一个详尽的例子理解：token 和专家的关系是几对几？一个 token 送给多个专家之后，token 数量会变多吗？

路由器的超参数有哪些？专家数量、top K 的 K；非常重要的专家容量系数：控制每个专家最大能接受多少的 token，为了负载均衡，N 个专家 一共 T 个 token，K 路由。公式是什么？辅助损失函数的系数。λ大小如何如何影响负载均衡。

路由器是线性吗？是纯线性的。因为只做加权打分，足够用，经过前面的注意力层，信息已经足够丰富。

加权这步有没有参数？没有。系数是路由器的打分经过 sofamax。

保证每个专家专精需要多大的训练量？不一定，可以用上面的公式简单看一下有没有达到负载均衡的计算量。

**不可导问题**：路由器很难从主任务的损失中直接学到哪个专家更适合哪个 token。

这个不可导到底带来的是什么问题？专家不好训练 还是选择哪个专家这一步不好训练？

某个 token 选择了专家一，进行前向计算得到损失，为什么这一次的损失对没选到的专家的参数梯度就是 0？从反向传播的链式法则看，那里的 Y 都不含其他专家的权重怎么能对他们的参数求导呢？更直白：损失函数 L 里面都没有他的参数，怎么求导？

所以说离散导致不可导问题，原因是，因为有一步离散操作，最后主任务的损失函数中没有路由器的权重参数，导致梯度大部分为 0.

如何解决这个问题？转化为让路由器选择专家之后，主任务的损失函数有路由器的参数。路由器不是单单根据打分结果 gate，离散地只留下最好的那个专家（此时损失函数没有任何 gate）；而是保留多个gate，加权求和的方式得到路由器的输出计算损失函数。此时损失函数包括 gate，而 gate 又是路由器的权重参数推出来的。

为什么选择专家时，Top2 要比 top1 更好？top1 有什么问题？只选择一个的话，他只会考虑如何调整专家一让损失更小，而关注不到直接选择专家二损失会更小。如何解决这个问题呢？ 引入辅助损失函数。引入噪音等等。

  embeddings = self.embedding(input_ids)
  
  # 上面代码，查表之后的输出形状：embedding ：[batch, seq_len, embed_dim]；背地里会把整数变成浮点向量、pad自动变成零向量；这张表的数字会在训练过程中根据损失不断更新
  
  ==================过程到底干了什么==========================
  for epoch in 范围:
      for input_ids, labels in dataloader:
  
          # 1. 前向传播（查表，拿到词向量）
          logits = model(input_ids)  
          # ↑ 这里用了 Embedding 表，但【还没更新】
  
          # 2. 算损失
          loss = criterion(logits, labels)
  
          # 3. 反向传播（计算所有参数要怎么改）
          optimizer.zero_grad()
          loss.backward()  
          # ↑ 这里会算出：
          #    - Linear 层怎么调
          #    - Embedding 表 每一行怎么调   在这里算！
  
          # 4. 更新所有参数（真正修改数值）
          optimizer.step()  
          # ↑ 这里会真正修改：
          #    - Linear 的权重
          #    - Embedding 表里的每一个值 在这里更新！
  ====================以上==================================
  ```

## 注意力机制

1解决模型输入的向量长度不确定

2.一般神经网络，输入一定，那么输出也一定；比如在判断句子中的词性，两个单词长一样，但是词性不一样。所以输出肯定要求不一样，怎么解决这个问题？让fully connect network 考虑得更多，上下文context咨询。把这些向量串起来，一起丢进神经网络。 “把向量串起来” 是有窗口大小限制的，输入的长度不确定，不可能让窗口无限大。 注意力机制就是解决这个问题，能覆盖所有输入之间的关系 。

自注意力机制是输入几个vector就输出几个vector吗； 

* 是的。每个新向量都对应之前的那个词，但是新向量的内容变了。而且向量的维度也不变，因为后面有残差连接。

self-attention是怎么做到考虑所有输入向量之间的联系的？输入有4个a向量，输出4个b向量；b1向量是怎么得到的？

*  先计算每两个向量之间的相关性；
* 如何计算两个向量的相关性，每个向量分别乘以预先训练好的矩阵，得到Q，K，V向量，再用当前向量的Q和每一个向量的K点积，得到衡量相关性的注意力得分。再经过Softmax（这些注意力得分有大有小有正有负，转化为加起来等于1的概率分布，对于一个输入向量的第i个元素的概率，分母都一样是所有元素的e指数全部求和，分子是这个元素的e指数），得到概率，再将每一个概率乘以对应向量的V，最终得到输出向量。此时输出向量具有上下文关系。
* Q代表当前词想要提取的信息；K代表这个词能提供什么信息；V代表这个词要被提取的信息；

**怎么理解self-attention没有向量之间的位置信息？**

* 我爱猫 和 猫爱我 这两种输入在self-attention眼里是完全相同的输入；语序一变整个句子的意思就变了。
* 在什么时候加？ 在第一次送入transformer层之前，只加一次。后续层会通过残差连接，位置信息自然保留到到高层。
* 怎么和初始向量结合：直接相加。
* 位置编码方法：正弦余弦位置编码

**多头注意力机制：**

* 为什么需要？ 相关性有很多方面。头1专门学主谓关系、头2专门学因果关系（关注因为所以这些关联词）
* 如何实现：经典参数举例：词向量的维度是512，一共8个头； 最终肯定要得到维度是512的向量。每个头的3个权重矩阵是，512*64 （把权重矩阵的第二个维度分成8份）； 然后经过点积、加权求和得到的输出向量的维度是64； 然后把8个向量直接拼起来拼成512维度。再乘以一个专门的大矩阵 512x512，把这 8 份来自不同侧面的信息，**线性融合**成最终的完整多头注意力输出。送入下一步的前馈神经网络。 

**缩放**

* 在得到注意力得分之后，Softmax之前，需要将每个得分除以根号下输入向量的维度。
* 原因：向量纬度越高，点积的绝对值会变得很大，经过Softmax之后，有一个概率会碾压其他所有概率，并且反响传播时，梯度消失，权重不更新。（存疑）
* Softmax的公式：对于一组输入向量，分子是什么、分母是什么？

self-attention相当于在普通的神经网络结构，加了一个步骤，考虑向量之间的联系对吗？

* 是的。

**编码器的结构**

* <img src="/images/tech-notes/llm01/image-20260507110351560.png" alt="Transformer 编码器结构" width="470" height="536" loading="lazy" decoding="async">
* 输入文本、分词、查嵌入表得到嵌入向量，加上位置编码，向量拼起来送入编码器。 编码器层的输入是上一层的输出。 编码器主要由2个部分，多头自注意力和前馈神经网络。这两部分，每一个后面都有残差连接和层归一化。
* 残差和层归一化出现的时机：每次向量送入自注意力或者前馈神经网络，都会开一条路直接连接到输出向量。
* 残差：直接把输出向量加上这一层原始的输入向量。为了保证能保留原始语义，消除梯度消失。
* 层归一化：为了防止数值漂移。步骤：先计算向量每一个位置的均值和方差，再标准化，然后用两个参数进行缩放和平移。 **缩放系数和平移系数是可调参数。** 每一个维度的两个系数是不同的。所有向量的同一个维度 归一化参数是相同的。
* 前馈神经网络：一个编码器层只有一个前馈神经网络，各个层之间的前馈神经网络的权重是相互独立的，不共享。
  * 作用：进行一次深度非线性加工，提炼更复杂的特征。
  * 组层：两个全连接层+激活函数；
  * 流程：输入 x → 线性层1 → ReLU激活 → Dropout → 线性层2 → 输出
* ​	编码器为什么设置层间权重不共享，为什么设置层内权重共享？
  * 层间权重不共享包括：注意力权重矩阵（每个头的投影矩阵、最后的拼接投影矩阵）、前馈网络的权重、层归一化的参数。
  * 作用：为了让不同层提取不同的特征。底层关注较浅的语法特征，高层关注更抽象的情感信息等等。
  * 层内权重共享：可以处理变长序列，减少参数量。

**解码器的结构**

* <img src="/images/tech-notes/llm01/image-20260507143937566.png" alt="Transformer 解码器结构" width="459" height="495" loading="lazy" decoding="async">
* 输入是什么？训练和推理时，输入不太一样；
  * 解码器的第一层掩码自注意力层的输入是什么，起始符号吗？
  * 推理时，输入的最开始是一个起始符< sos>，生成第一个词“我”；然后输入更新为  sos 我； 再次跑整个解码器，知道输出结束符eos停止。
  * 训练时，输入是目标语言句子（比如要生成的翻译结果）整体右移一位，并且前面加上起始符，由于有掩码，所以看不到当前位置的后面。
* 三部分构成：掩码注意力层、交叉注意力层、前馈神经网络层。（每个层后面都有一个残差连接和层归一化）
* 掩码自注意力：
  * 为什么需要掩码？训练时防止信息泄漏，预测时防止崩溃、瞎预测。
  * 掩码的具体实现：推理和训练时，不太一样。
    * 基本思路是：Q和V点积之后得到原始分数矩阵，在进行加权求和之前，把这个矩阵加上一个掩码矩阵，使得，在softmax时候，当前位置对他未来位置的注意力权重都是0。 具体实现：得分矩阵加上一个掩码矩阵，这个矩阵的对角线及其左下角全零，右上角是负无穷，这样做之后，每个位置的未来位置的注意力权重就是0。
    * 推理时，解码器是串行生成一个个向量。输入序列也是逐步增长。推理的时候，也看不到没有生成向量的K。所以第一次做点积QV，只有这个向量和第一个位置的K做点积。 但是掩码并不多余，可以防止看到后面的空位。

* 交叉注意力层

  Mamba思考：如何在没有注意力矩阵的情况下，实现Transformer中跨注意力层的这种跨序列状态融合。

  * Q来自解码器自己，就是上一层掩码自注意力的输出；K和V来自编码器最终的输出。编码器最终的输出被解码器每一层共享，作为字典反复查询。目的是，让解码器回顾源句的意思。
  * 具体计算流程：编码器输出的矩阵E（行数是向量的个数，列数词向量的维度数，把向量当作行向量拼起来，记住这个规则） ，解码器上一层输出的矩阵是H。 Q是H乘以权重矩阵生成，K和V是E乘以权重矩阵生成。然后计算注意力分数，加权求和，残差连接，层归一化。

**线性层和Softmax层**

* transformer的最终决策层。在总的词汇表中找出得分最高的那个，作为当前输出。

* 具体过程：把解码器输出的矩阵（3个词，就是3个512维的向量），乘以一个权重矩阵512X30000，（词汇表一共30000个词），得到一个新的矩阵，矩阵的每一行就是 这个词向量对应词汇表中每一个词的原始得分。原始得分有正有负，进过Softmax，变成权重，选择权重最大的那个位置对应的词作为输出。

* 具体过程：

* ```
  
  第1步：生成第1个词 “我”
  解码器输入：只有 1 个词，即起始符 [<sos>]。
  
  编码器输入：整句完整的 “I love cats”。
  
  过程：编码器输出 E (3×512)，解码器输入 [<sos>] 处理。
  
  解码器输出矩阵：1 × 512 （因为输入只有1个词）。
  
  线性层取哪一行？：取这 仅有的一行（对应 <sos> 位置）。
  
  Softmax结果：预测出下一个词是“我”。
  ==================================================
  
  第2步：生成第2个词 “爱”
  解码器输入：拼上新词，变成 [<sos>, 我]，共 2 个词。
  
  编码器输入：依旧是完整的 “I love cats”。
  
  过程：编码器 E 不变(3×512)，解码器重新跑一遍整个输入序列。
  
  解码器输出矩阵：2 × 512。
  
  线性层取哪一行？：取 最后一行（即“我”对应的那个输出向量）。
  
  Softmax结果：预测出下一个词是“爱”。
  
  关键：第一行 <sos> 的输出这次我们不关心，我们只关心用最新的词预测下一个词。
  ==================================================
  
  第3步：生成第3个词 “猫”
  解码器输入：[<sos>, 我, 爱]，共 3 个词。
  
  解码器输出矩阵：3 × 512。
  
  线性层取哪一行？：取 最后一行（即“爱”对应的那个输出向量）。
  
  Softmax结果：预测出下一个词是“猫”。
  ==================================================
  
  第4步：生成结束符 <eos>
  解码器输入：[<sos>, 我, 爱, 猫]，共 4 个词。
  
  解码器输出矩阵：4 × 512。
  
  线性层取哪一行？：取 最后一行（“猫”对应的向量）。
  
  Softmax结果：预测出 <eos>，停止生成。
  ```

  以上过程可以看出，编码器每次输出的矩阵是逐渐变大的，并且取最后一行送入线性层然后生成最终结果。

**transformer的训练和推理**

* 训练：完整地输入原句和目标句，生成完整的嵌入向量。训练时完整的目标句整体右移一位加上起始符号，作为解码器输入，用掩码保证每个位置只看到过去。 如何理解：模型并行计算所有位置的预测，一次性算出整体损失。 训练时目标句嵌入是完整的，一次性的。
* 推理：没有完整的目标句，一步步生成。每一步都把已经生成的前缀做嵌入和位置编码，送入解码器。 推理时，目标句嵌入一直在用，不过tgt长度在增长，内容在更新。

transformer用注意力机制提高模型的训练速度。（为什么）

transformer的结构：由一个编码器和解码器构成，编码器由6个编码器组件组成。（编码器组件的个数属于可调参数） 编码器组件的结构相同，都是由一个自注意力层和一个前馈神经网络构成。但是编码器组件之间的权重不同。解码器组件相比编码器组件多了一个注意力层，让解码器能够注意到输入句子的相关部分。

**第二个可调参数，是编码器接收的向量长度（向量的维度）。一般来说是训练集中长度最长的句子的长度。**

**时间复杂度分析**

嵌入向量是什么？ 

* 词经过查嵌入表得到嵌入向量。

* 就是一个词经过嵌入模型生成对应的向量，这个向量具有固定长度。（更强调学习过程）
* BERT：能把自然语言变成充满上下文信息的向量。本身不做任何应用，但是微调后可以做大量NLP任务。BERT 虽强，但受限于 O(n²) 复杂度，处理很长的文档时必须切成短块，可能丢失跨块信息。  因为BERT底层还是transformer的编码器部分。

Transformer 的前向计算中，流程：

输入文本 → 分词 → 查嵌入表得到嵌入向量 → 加上位置编码 → 送入自注意力层

transformer结构的编码器和解码器是如何配合的？编码器的输出要给解码器的每一个层吗？

* 编码器的输入、输出是什么？输入：源语言经过嵌入和位置编码后的向量序列。输出：同样长度的向量，但是每个向量有上下文关系。
* 编码器首先处理输入序列。生成一组具有上下文关系的向量。
  * 生成的向量，又会被投影成一套K和V，作为字典，供解码器使用；解码器生成一个词，就用自己的Q和编码器生成的那些K做点积，得到注意力分数，然后权重（分数soft Max一下）乘以V抽取相关内容。
  * 这一部分就是Cross attention，连接encoder和decoder的桥梁。
* 解码器的自注意力加掩码是什么意思？解码器生成时是自回归的什么意思？解码器为啥要生成词？我有点不懂逻辑了。
* 编码器的QVK是怎么生成的？解码器的QVK是怎么生成的？
* 如何理解“解码器每生成一个词时，拿着自己当前的“我想表达什么”（Q），去编码器输出的源句子所有位置上，问“你这儿有什么相关信息？”（K），然后根据匹配度，从编码器输出里提取相应的内容（V），融入解码器。”
* 编码器的同一套最终输出，都会原样的传给解码器的每一层，所以每一层根据自己的跨注意力子层提取出自己需要的内容。

Seq2seq 是一类任务统称，模型架构的统称。transformer是seq2seq现在最强的实现。

```
编码器 (Encoder)         解码器 (Decoder)
   ↓                        ↓
把输入序列“读懂”，      拿着编码器给的“理解”，
压缩成一套向量表示。     一个接一个地生成输出序列。
```

Decoder 的每次输出一个向量， 比如机器翻译，数据库有2000个汉字，那就生成一个长度2000的向量，每个汉字对应一个位置有一个打分，然后取最大的那个分数。

decoder的注意力层是 masked self-attention，每次产生新的向量时，只能利用之前已经产生过的向量。

decoder是一个接着一个生成的，还要能够判断何时停止生成。所以整个数据表除了汉字，还需要有一个结束符号。

**我理解的计算自注意力的机制**

首先源文本，先经过切分成为一个个词，词查嵌入表得到嵌入向量，此时的嵌入向量是没有上下文关系的，然后把这一系列向量送入自注意力层。首先， 每个向量都经过权重矩阵，W Q W K W V生成对应的Q，K，V。一个向量的Q和其他所有向量的K做点积，得到N个得分，再soft Max一下，然后权重对所有的V进行加权求和，得到新的向量表示，这个新的向量表示就具有了这一段文本的全局信息。
